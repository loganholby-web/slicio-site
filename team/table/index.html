Set up the table

Like iPad A or Table 2. Every rating is saved with it, so the results can tell devices apart. One device, one name.

One page per pizza with the taste test name, the pizza and a small sheet label, and 24 numbered lines for a star, yes or no, and a comment. The card code is never printed, so a sheet cannot be used to rate for a crust.

How to run the table
  1. One device per table. Use an iPad or a phone with a staff account signed in, and give it a name above.
  2. Lock it to this page. On an iPad, turn on Guided Access (Settings, Accessibility, Guided Access), open this page, then triple-click the side button. On Android, use Screen pinning.
  3. Tasters do not sign up. They do not type a name. They tap a pizza they tried, tap stars, and tap Save. A comment and Yes or No are optional.
  4. Next taster. When a taster is done, tap Next taster. If someone tapped at random, tap Undo this taster.
  5. Bad Wi-Fi is fine. Ratings wait on the device and send by themselves. The top of the table says All saved when nothing is waiting.
  6. Stay with the table. The device is signed in as staff. Do not leave it alone with tasters.
  7. When you are done, wait for All saved, then tap Lock the table. It signs the device out.
